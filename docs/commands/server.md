# Server commands

## `/server plugins`

Quick DupeDB plugin-list scan (lighter probe set).

```
/server plugins
```

Exploit-gated on restricted servers.

## `/serversearch`

Opens the server search auth screen for DupeDB server tooling.

```
/serversearch
```
