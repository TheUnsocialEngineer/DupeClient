# Vault commands

Server password vault (encrypted storage). Open the UI from **Security** panel > **Open password vault**.

```
/vault
/vault save
/vault dismiss
/vault lock
```

| Command | When to use |
|---------|-------------|
| `save` | Confirm a pending save after editing an entry (vault must be unlocked) |
| `dismiss` | Cancel pending save prompt |
| `lock` | Lock the vault immediately |

See [Security module](../modules/security.md).
