# Utility commands

## `/looknbt`

Copy NBT from the block or entity you are looking at to the clipboard.

```
/looknbt
/looknbt print
/looknbt chat
```

## `/nbtedit`

Open the NBT editor for the item in your main hand.

```
/nbtedit
```

## `/dupe`

Client-only troll helper: fills hotbar and prints fake dupe messages locally.

```
/dupe diamond 64
```

Does not create real items on servers.
