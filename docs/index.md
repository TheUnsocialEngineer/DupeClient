## Default keys

| Action | Key |
|--------|-----|
| Open module hub | Right Control |
| Open macro studio | F7 |

Rebind under **Options > Controls > DupeClient**.

## Config location

All settings: `.minecraft/config/dupeclient/`

Macros: `.minecraft/config/dupeclient/macros/`
