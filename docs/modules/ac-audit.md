# AC Audit

Live anticheat and platform metrics while playing.

![AC Audit panel](assets/screenshots/panel-ac-audit.png)

![AC Audit overlay](assets/screenshots/overlay-ac-audit.png)

## Metrics

- Server brand and platform classification
- TPS, ping, packet rates, setback stats
- Discovered plugin namespaces and anticheat hints
- Slot sync probes

Use with DupeDB: scans prioritize namespaces from AC Audit detections.
