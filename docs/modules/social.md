# Social

Online DupeClient users, friends, and shared server join.

**Presence API:** `https://dupeclient-presence.vercel.app/api/client/presence`

![Social panel](assets/screenshots/panel-social.png)

![Social screen](assets/screenshots/screen-social.png)

## Screen tabs

| Tab | Purpose |
|-----|---------|
| Online | User list with server and coordinates (when shared) |
| Settings | Presence visibility, friends-only list, waypoint sharing |

## Row actions

| Action | How |
|--------|-----|
| Join server | Join button when address is shared |
| Friend toggle | Right-click > Add/Remove friend |
| Send bots to me | Right-click friend (MCPTools) |
| P2W badge | Shown on server lines when registry has data |

Configure hotkey for Social screen in the Social hub panel.
