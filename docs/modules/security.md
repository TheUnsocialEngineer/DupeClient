# Security

## OpSec

| Setting | Purpose |
|---------|---------|
| Key resolution protection | Spoof mod key probes on remote servers |
| Fake default keybinds | Vanilla-style bind spoofing |
| Brand / whitelist modes | Fabric vs vanilla behavior |
| Per-server profiles | Auto-load saved OpSec on join; save current server profile from hub |

## Staff detection

Alerts for staff join/leave, proximity, glow, and invisible entities. Staff timeline log shows recent detection lines in the panel.
