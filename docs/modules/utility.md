## Fuzzers

![Fuzzer overlay](assets/screenshots/overlay-fuzzer.png)

Hub sub-tabs:

| Tab | Purpose |
|-----|---------|
| Chat games | Solver settings |
| Crashes | Stress/crash utilities (policy gated) |
| Economy fuzzer | Economy command fuzzing |
| SQLi | SQL injection probe strings |
| MiniMessage | MiniMessage format probes |

Exploit utilities are disabled on non-P2W registry servers.
