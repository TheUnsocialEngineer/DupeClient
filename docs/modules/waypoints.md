# Waypoints

Personal and shared waypoints with audience control.

![Waypoints panel]({{ site.baseurl }}/assets/screenshots/panel-waypoints.png)

![Waypoints screen]({{ site.baseurl }}/assets/screenshots/screen-waypoints.png)

## Create and share

1. Open Waypoints screen from hub hotkey.
2. **Create here** while standing at the location.
3. Set share audience: Everyone, Friends, or Only me.

## Context menu (right-click row)

| Item | Action |
|------|--------|
| Path here | Baritone path to coordinates |
| Edit | Open editor |
| Delete | Remove local waypoint |

Shared friend waypoints appear read-only unless you own them.
