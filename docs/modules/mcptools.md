# MCPTools

Bot tooling with local runner or remote execution. Bundle syncs from the configured presence API manifest endpoint.

![MCPTools panel]({{ site.baseurl }}/assets/screenshots/panel-mcp-tools.png)

![MCPTools overlay]({{ site.baseurl }}/assets/screenshots/overlay-mcptools.png)

## Features

- Tool selection and host/port settings.
- Bot fleet add/remove, goto, mine helpers.
- Bundle sync with changelog toast on version change.
- Social: right-click friend > **Send bots to me** paths bots to your position.

Remote runner mode disables some local bot fleet actions.
